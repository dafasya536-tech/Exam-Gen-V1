# Exam Generator 🚀

Aplikasi berbasis Google Apps Script untuk membuat Google Form Ujian (Kuis) secara instan dari teks dan data Excel. Dibuat khusus untuk memudahkan tugas guru.

## 🌟 Fitur Utama
* Mendukung format Pilihan Ganda, Dropdown, Menjodohkan, dan Jawaban Singkat.
* Impor nama dan kelas siswa langsung dari copy-paste Excel.
* Tampilan antarmuka (UI) raksasa yang 100% responsif dan nyaman digunakan di HP.
* Mendukung instalasi sebagai aplikasi mandiri (PWA) di layar utama HP.

## 💻 Teknologi yang Digunakan
* HTML, CSS, dan JavaScript
* Google Apps Script (Backend)
* Google Forms API & Google Drive API
